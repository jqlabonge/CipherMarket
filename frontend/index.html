The Black Box Bazaar

not connected
An on-chain marketplace for cryptographic vulnerability disclosure.

Flagship vertical: ECDSA nonce reuse. A seller claims a target account's signer reused a nonce across two signatures. The full finding stays hidden until a buyer pays into escrow -- payment only releases if the contract's own ecrecover-based check confirms both signatures really do recover to the target account over two different messages. No oracle, no human judge: the math is the verifier.

Simulate a vulnerable target (demo data only)

Real signers derive each signature's nonce deterministically from the message (RFC 6979) specifically so nonces never repeat. To have something real to disclose in this demo, this generates a synthetic "target" keypair and a toy signer that intentionally reuses a nonce across two signatures -- entirely offline, in your browser, using toy-vulnerable-signer.js (no real key, no real funds, never sent anywhere). This is exactly the bug class the marketplace exists to disclose.

Testnet demo only. No real vulnerabilities, real private keys, or operational exploit material are used or required. See README.md for trust assumptions and limitations.
